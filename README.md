## Deploy (free)
### Vercel (recommended)
1. Go to vercel.com → New Project
2. Upload this folder or drag index.html
3. Deploy → done in 30 seconds

### Netlify
1. Go to netlify.com → Sites → Drag & drop
2. Drop this folder → live instantly

### GitHub Pages
1. Push to a GitHub repo
2. Settings → Pages → Deploy from root
3. Your site is live at username.github.io/repo
